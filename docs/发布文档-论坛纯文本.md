━━━━━━━━━━ 一、这是什么 ━━━━━━━━━━

Gopeed 是一个用 Go + Flutter 写的现代下载器，支持 HTTP / HTTPS / BitTorrent / 磁力 / Metalink，自带完整的 Web 界面。官方 Web 版本身是「一个二进制 + 一个端口」，我把它做成了飞牛原生应用包，补上了桌面图标、安装向导、权限、HTTPS 入口这些 NAS 上才需要的部分。

和「自己拉个 Docker」的区别：

・原生 fpk，不依赖 Docker，也不用装 Node / Python（隧道用到系统自带的 python3）
・桌面图标直接嵌在飞牛桌面里打开，和原生应用体验一致
・内网 http 桌面、外网 https 桌面同一个端口都能打开（不用两套配置、不用反代证书）
・下载文件的属主 = 你指定的飞牛用户，文件管理器里能正常改名、移动、删除
・安装向导里一次填好账号、下载目录、BT/ED2K 端口，装完即可用


━━━━━━━━━━ 二、功能特性 ━━━━━━━━━━

下载能力
・HTTP / HTTPS 直链下载，支持多连接、断点续传
・BitTorrent / 磁力链接，支持做种、自定义 Tracker
・Metalink
・全局并发数、单任务连接数、限速等常规设置

NAS 适配（本移植包的重点）
・桌面图标打开：飞牛桌面 iframe 内直接使用，不跳新标签页
・http + https 同端口：桌面是 http 就用 http，是 https 就用 https，都是 38099
・IPv4 + IPv6 双栈：纯 IPv6 的 DDNS 域名也能打开（不会出现「只有 AAAA 就白屏」）
・运行身份可选：引擎以你指定的飞牛用户运行（等价 Docker 的 PUID/PGID）
・下载目录可选：留空用共享目录，填绝对路径用你自己的目录
・配置自动同步：应用设置里改的下载目录、BT/ED2K 端口，每次启动都会写回引擎（Gopeed 只在首次初始化存储时读一次种子配置，不主动同步的话重装就会丢失）
・删除任务兜底清理：Gopeed 删除单文件任务时只删最终文件名，未完成的数据叫「文件名.part」，会残留。单任务删除时本包会补删这个 .part（界面的批量删除仍会遗留，见「已知问题」）
・卸载可选：保留配置/任务，或者全部清空


━━━━━━━━━━ 三、安装 ━━━━━━━━━━

1. 按设备架构下载安装包
　x86_64（绝大多数 N100 / J4125 / i3 机型） → gopeed-1.9.3-14-x86.fpk
　ARM64（瑞芯微等） → gopeed-1.9.3-14-arm.fpk
2. 飞牛「应用中心 → 手动安装」，上传 .fpk
3. 按向导填写（每项都有默认值，直接下一步也能用）

　登录账号：admin（Gopeed 页面的登录名）
　登录密码：空（留空 = 不开启登录保护，装完直接进任务列表；要外网访问请务必设一个）
　运行身份（飞牛用户）：空 = 保持当前（首装为 admin）。决定下载文件的属主与可写范围
　默认下载目录：空。留空 = 共享目录 gopeed/downloads；填绝对路径则用该目录
　BT 监听端口：51413（刻意避开 6881-6889，部分运营商对这几个端口限速）
　ED2K TCP / UDP：4662 / 4672（固定才可能拿到 eMule HighID）
　启动时自动续传：开（只是首启默认值，之后在 Gopeed 设置里改）

4. 装完点桌面图标，或直接访问 http://<飞牛IP>:38099 （设了密码的话用向导里的账号登录）

关于「运行身份」：飞牛的 /vol* 目录带 trimacl，POSIX ACL（setfacl）在上面不生效——所以应用脚本以 root 启动，再把引擎降权到你指定的这个用户，效果等同于 Docker 的 PUID/PGID。选谁，下载下来的文件就归谁。


━━━━━━━━━━ 四、端口说明 ━━━━━━━━━━

Web 界面（http/https 同端口）：38099 / TCP　→ 要外网访问才需要在路由器上映射
BitTorrent：51413（TCP + UDP）　→ 想提升 BT 速度/做种时需要映射
ED2K：4662/TCP、4672/UDP　→ 想拿 HighID 时需要映射

・内网直接 http://IP:38099 即可，不需要任何映射
・外网访问请映射 TCP 38099（https 桌面里的 iframe 是直连「域名:38099」的）
・IPv6 直连不用映射，只要防火墙放行 38099
・走 https 请用域名，用 IP 访问会拿到飞牛自签的兜底证书（浏览器会提示不受信）

端口为什么不能装的时候选：飞牛在安装那一刻就把入口地址写进桌面图标了，向导里的端口变量不会被替换。需要别的端口只能改 build.py 重新出包（见仓库 README）。


━━━━━━━━━━ 五、下载目录与文件权限 ━━━━━━━━━━

三种用法：

1. 留空：用系统为本应用创建的共享目录，安装后在「文件管理」里是 gopeed/downloads，最简单，权限也是现成的
2. 填绝对路径：例如 /vol1/1000/Downloads，安装时会自动创建并授权给运行身份
3. 安装后在 Gopeed 界面里改：设置 → 下载 → 默认下载目录

改完目录后，分类目录（音乐/电影等）的相对路径仍然生效；如果填的是绝对路径，记得让运行身份对它有写权限，否则任务会报 permission denied。


━━━━━━━━━━ 六、日常修改配置 ━━━━━━━━━━

应用中心 → Gopeed → 设置，可以改：

・登录账号 / 密码
・运行身份（飞牛用户）
・默认下载目录
・BT 监听端口、ED2K TCP / UDP 端口

保存后应用会自动重启，已下载的文件和任务进度都保留。


━━━━━━━━━━ 七、升级与卸载 ━━━━━━━━━━

升级：应用中心里「手动安装」新版本包即可；也可以先卸载再装（卸载时选「保留配置」，任务列表和设置都不会丢）。飞牛的命令行工具 appcenter-cli 目前不支持原地升级，所以推荐用应用中心图形界面覆盖安装。

卸载：向导里有两个单选
・保留（默认）：只删程序，@appconf / @appdata 都在，重装后账号、设置和任务列表原样回来
・不保留，全部清空：删除 gopeed.conf（账号/密码/端口/下载目录）、任务数据库 gopeed.db（任务列表与进度）、扩展、缓存、日志、临时文件、隧道证书副本 —— 重装等于全新安装
・两种选择都不会删下载目录里的文件，也不会动共享目录 gopeed/downloads


━━━━━━━━━━ 八、常见问题 ━━━━━━━━━━

Q：装完打不开 / 一直转圈？
先确认端口没被占用：SSH 里 netstat -tlnp | grep 38099 。如果 38099 已经被别的服务占了，需要重新构建一个不同端口的包（仓库 README 里有 python build.py --port 38123 的用法），不能只在配置文件里改端口——桌面图标指向的是构建时固化的地址。

Q：外网 https 打开一片空白？
两个原因，按顺序查：
1. 路由器没把 TCP 38099 转发到飞牛（https 桌面里的 iframe 是直连「域名:38099」的，不是走反代）
2. 用 IP 访问 https。隧道是按 SNI 选证书的，用 IP 只能拿到兜底证书、连接会失败，请用域名

Q：纯 IPv6 的 DDNS 域名打不开？
隧道已经同时绑 0.0.0.0 和 [::]（双栈），如果还不通，检查飞牛防火墙有没有放行 38099。

Q：下载任务报 permission denied / 文件下不下来？
运行身份对目标目录没有写权限。要么改用共享目录（留空），要么把运行身份换成对该目录有权限的用户。注意 /vol* 是 trimacl，用 setfacl 授权是不生效的，得在飞牛的用户/共享目录权限里给。

Q：BT 速度慢 / 一直没速度？
1. 设置里确认 BT 监听端口是 51413（显示 0 表示随机端口，收不到入站连接）
2. 路由器上把 51413 TCP + UDP 转发到飞牛；IPv6 只需防火墙放行
3. 冷门种子本身就没 peers，和 NAS 无关

Q：删除任务后文件还在？
先看那个对话框：勾了「保留已下载的文件」就只删任务、文件保留，这是 Gopeed 本来的行为。没勾的话，完成的任务文件会被删掉；但没下完的 .part 分片目前只有「单个任务删除」这条路径会兜底清理，界面上用批量删除时可能留下 .part，需要到文件管理器里手动删一次（下个版本会补齐）。

Q：装完就能用吗，要输密码吗？
向导里密码留空的话不开启登录保护，点开就直接是任务列表（内网自用很方便）。外网访问或者有别的用户在用这台 NAS，建议在向导里或应用设置里设一个密码。

Q：忘记登录密码了？
应用中心 → Gopeed → 设置里可以重设。如果连应用设置也进不去，卸载时选「全部清空」后重装即可（会丢任务列表，下载好的文件不受影响）。

Q：怎么关闭登录保护（内网懒得输密码）？
设置向导里「留空」表示不修改，不会把密码清掉。要关掉就直接改配置再重启应用：
sudo sed -i 's/^WEB_PASS=.*/WEB_PASS=""/' /var/apps/gopeed/etc/gopeed.conf
然后在应用中心把 Gopeed 停用再启用。

Q：能和 Docker 版同时装吗？
可以，只要端口不冲突（Docker 版通常映射 9999，本包固定 38099）。


━━━━━━━━━━ 九、已知问题 ━━━━━━━━━━

・Web 端口不可在安装时选择：飞牛把入口地址固化到桌面图标，只能构建期决定（默认 38099）
・命令行 appcenter-cli 不支持升级安装：换包请用应用中心图形界面，或「卸载 → 重装」
・用 IP 访问 https 会提示证书不受信：请用域名
・批量删除任务时 .part 分片可能残留：目前兜底只挂在单任务删除这条路径上，界面里的批量删除走的接口不同；下个版本补齐，在此之前请手动删除残留的 .part
・本项目不是 Gopeed 官方发布：只是打包，上游行为（包括上面这些）以官方为准
・ARM64 包已通过架构校验和 qemu 下的启动验证，但还没有在真实 ARM 设备上长期跑，欢迎反馈
